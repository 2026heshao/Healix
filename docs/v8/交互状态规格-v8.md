# Healix v8 · 交互/状态规格（原型设计输入）

> 定位：原型（HTML）的输入规格，不是完整 PRD。范围 = 4 块拍板项的状态细化与边界覆盖。
> 硬约束（全文生效）：全局 1 强调色 `#B85028`；正/负色仅用于文字与 6px 圆点；无卡片/无阴影/无渐变；圆角全局 8dp（线高 ≤2dp 元素可 1dp，仅限进度线/Tab 下划线/accent 竖线）；字重仅 400/500；层级只由字号/字重/灰度决定；令牌 bg`#FAFAF9`/surface`#FFFFFF`/text_1`#1A1918`/text_2`#6E6B66`/text_3`#9C9891`/line`#EAE8E4`/accent`#B85028`；字号 numeral36/title17/body15/secondary13/caption12；左右边距 20dp、区块间距 28dp、触控 ≥48dp。

## ① 记录页「目标区」压缩（问题4 · 300–360dp → ≈140dp）

### 功能规则
| 元素 | 结构 | 高度预算 | 交互 |
|---|---|---|---|
| 主目标行 | 左：主目标名（title17/text_1）+ 当前值（secondary13/text_2，紧随其后）；右：`去调整 ›`（secondary13/text_2） | **48dp**（满热区） | 点击整行 = 去调整；`›` 为视觉提示不单独响应 |
| 分隔线 | 1dp `line`，左右各 20dp 内缩 | 1dp | — |
| 三卡横排 | 本周训练 / 近7日睡眠 / 近30日体重，等宽各 1/3；每卡 = caption12(text_3) 标题 + 迷你 sparkline（高 20dp）+ numeral/body 当前值 | **56dp** | 点任一卡 → 半屏详情弹层，默认定位到该 metric |
| 今日盈余摘要 | 单行：`今日盈余` caption12(text_3) + 数值(numeral 36→此处用 body15/text_1，随正负用 `#4A7C59`/`#A63D40`，前置 6px 圆点) + `›` | **32dp** | 点击 → 详情弹层（不切换 metric，进入"盈余"视角） |
| 区块外间距 | 与上方输入区之间 28dp（沿用区块间距） | — | — |

**合计 ≈ 48 + 1 + 56 + 1 + 32 = 138dp（<20% 屏高，满足）。**

**三卡点击跳转规则**：三卡共用一个详情弹层（半屏 BottomSheet），弹层顶部为三选一文字 Tab（选中 text_1 + 2dp accent 下划线（圆角 1dp）/ 未选中 text_2），点哪张卡就以哪个 metric 为初始选中项；弹层内切换 Tab 只换折线，不关闭。
**「去调整」去向**：打开 `GoalSetupSheet`（**编辑态**，预填当前主目标与目标体重），与首启引导同一组件；保存后就地返回记录页、主目标行即时刷新。**不跨页跳设置栏。**
**详情弹层关闭方式**：① 下滑手势；② 点击遮罩；③ 右上角 `关闭` 文字按钮（secondary13/text_2，满足可发现性与无障碍，不用 X 图标）。
**弹层内容**：大折线图（高 ≈180dp，1dp 基线 + 8dp 端点圆）/ metric 当前值 + 目标值 / `改目标 ›`（→ GoalSetupSheet 编辑态，定位该 metric）/ 其余两个次目标的快捷切换 / `添加其他目标`（→ 设置›目标栏）。

### 状态覆盖
| 状态 | 表现 |
|---|---|
| 空（无任何目标） | 目标区塌缩为单行 48dp：`还没有目标` caption12(text_3) + `添加目标 ›`（text_2）；三卡与盈余行隐藏 |
| 加载 | 不出现独立 loading 区；骨架 = 主目标行显示 `—`，三卡占位（见下），盈余显示 `—`；不引动效 |
| 成功 | 正常渲染；sparkline 为 1dp 折线（accent 用于"实际"，`line` 用于零基准） |
| 失败（本地库读失败） | 沿用空态样式 + 13sp text_3 `读取失败，点击重试`（整行可点重试） |
| 禁用 | 无（目标区无禁用态；无 AI 依赖） |

### 边界与异常
- **数据不足（<3 点）**：0 点 → 值显示 `—`，迷你图位置显示 caption12(text_3)`暂无记录`；1–2 点 → 值正常显示，迷你图只画 2dp 圆点(s) 不连折线，图下/旁 caption12(text_3)`攒够 3 次看趋势`；≥3 点 → 正常折线。弹层大图同规则（0 点显示居中 text_3 `记录 3 天后生成趋势`）。
- **隐私隐藏体重**：体重卡标题保留，值显示 `••••`（text_2），迷你图不绘制（保留 20dp 空高，不塌陷）；点击该卡仍在原位弹层，弹层内体重同样打码，并给出 `显示一次` 文字按钮（secondary13/text_2，按下 accent）——仅本次会话显示，关闭即恢复打码。
- **主目标未设**：主目标行左显示 `未设置主目标` (text_2)，右侧 `去设置 ›`；盈余行隐藏。
- 迷你 sparkline 用 accent 单色，不加渐变/填充面，符合"不铺面"约束。
- **目标个数不影响布局（重要）**：三卡**恒为「每周训练 / 睡眠 / 体重」三项**，与用户启用了几个次目标无关；热量 / 饮水不占卡位，只在次目标详情弹层的「其他目标」区出现。因此目标区高度恒为 ≈138dp —— 即使次目标加满 5 个，也不会撑高、换行或溢出。

## ② 设置页「目标」栏（问题2）

### 功能规则
**2a · 新增热量槽位（metric `kcal_daily`）**
- 目标栏 = 主目标（置顶，不可删）+ 一组「次目标」行（可增/删/改）+ 底部常驻 `+ 添加目标`。
- **排序位置**：`主目标 → 热量(kcal_daily) → 体重 → 每周训练 → 睡眠 → 饮水`。热量紧邻主目标，因它是增重/减重的量化执行口径。新增项一律插入对应语义位（非一律追加到末尾）。
- 每行结构：metric 名(body15/text_1) + 当前值(secondary13/text_2；未设显示 `未设置` text_3) + 右 `›`；行高 ≥48dp，行间 1dp `line`。
- `+ 添加目标` 行为：弹出可选项列表（体重/热量/每周训练/睡眠/饮水），已存在的 metric 置灰不可选。
- **kcal 编辑入口迁移**：kcal 的编辑统一在目标栏行内完成（点行 → 编辑弹层）；**个人信息页移除「每日热量目标」行**，不再保留任何目标类字段。
  - 老入口处理：直接移除，不做跳转占位；升级后**首次**进入「目标」栏时，栏顶显示一次性可关闭 hint（13sp text_2）`热量目标现已移至此栏`。

**2b · 删除默认种子，仅保留主目标首启引导**
- 全新安装**不再静默种 6 行默认目标**（含主目标=增重）。
- 仅保留**主目标首次引导** `GoalSetupSheet`：`增重 / 减重 / 保持`（单选）+ `目标体重`（数字，可留空）；含 `跳过`。跳过后主目标行显示 `未设置主目标`，其余槽位不自动创建。
- 其余槽位仅由用户 `添加目标` 显式创建。

**空态与入口**
- 空态（仅主目标/无任何次目标）：目标栏内主目标行下显示 caption12(text_3) `还没有次目标`，紧接着 `+ 添加目标`。
- 完全空（含主目标也未设）：首行 `未设置主目标 · 去设置 ›`，其下 `+ 添加目标`。
- `+ 添加目标` **常驻栏底**（非空态也在），保证唯一显式创建入口。

**两入口收敛规则**
- 设置›**目标栏**：所有"可增删/可改的数值目标"唯一归属（主目标、体重、热量、每周训练、睡眠、饮水）。
- **个人信息页**：仅保留非目标静态档案（身高/年龄/性别/活动水平等）；不再承载任何目标数值，也不再有指向 kcal 的入口。
- 记录页「去调整」不经个人信息页，直接开 GoalSetupSheet（见 ①）。

**老用户 TARGET_KCAL 迁移**
- 已设 `TARGET_KCAL` → **静默保留其值**，映射为 `kcal_daily` 目标行（`status=active`）插入目标栏，不弹窗、不改值、不丢失；同时触发上面的迁移 hint。
- 未设（空/0）→ 不创建行；无迁移提示。

**删光后首页目标区回落**
- 用户删光所有次目标（且主目标保留）：首页目标区按 ① 的"次目标为空"处理——主目标行保留，三卡降级为单行 `添加目标 ›`（48dp），盈余行按主目标是否可算决定显隐。
- 主目标也"跳过"未设：目标区=单行 `未设置主目标 · 去设置 ›`（48dp）。

### 状态覆盖
| 状态 | 表现 |
|---|---|
| 空 | 见上「空态/完全空」；无插画、无卡片，纯文本 + 文字入口 |
| 加载 | 行以 `—` 占位，无闪烁骨架 |
| 成功 | 行即时增/删/改并持久化；主目标变更后在记录页目标区即时反映 |
| 失败（写入失败） | 行内联 error(13sp text_2) `保存失败，重试`；回滚到改前值 |
| 禁用 | `+ 添加目标` 在全部槽位已添加时置灰（text_3，不可点），同行右侧 caption12(text_3) `已达上限 6 项`；点按无响应（**不再**"看起来能点、点完才弹 Toast `所有目标都已启用`"） |

### 边界与异常
- 删除主目标：不允许（无删除入口）；仅允许"更改"。
- 删除某次目标的确认：轻量确认（`删除该目标？` 二次点击/短确认条），不弹系统对话框；删除 = 归档（`goals.status=archived`），非物理删除。
- kcal 与主目标冲突（如减重却设高热量）：允许并存，仅以 caption 提示，不阻断。
- 数值单位与范围：kcal 100–9999 整数；体重 20–300kg（沿用既有校验）。

### 目标数量上限（护栏 · 本轮新增）

**上限 = 6 项**：主目标 1 + 次目标 5（体重 / 热量 / 每周训练 / 睡眠 / 饮水）。

| 项 | 结论 |
|---|---|
| 上限来源 | **不是计数器，而是槽位白名单天然封顶**：`GoalSlots.ALL`（现 5 槽位，加 kcal 后 6）是唯一可加集合，「添加目标」只列该集合中**当前未启用**的槽位；加满后列表为空 |
| 达上限表现 | `+ 添加目标` 置灰（text_3）不可点 + 同行右侧 caption12(text_3) `已达上限 6 项`；点按无响应 |
| 何时恢复 | 左滑归档任一次目标后，该槽位重新出现在「添加目标」列表，入口恢复强调色 |
| 对记录页的影响 | 无 —— 三卡恒为训练 / 睡眠 / 体重，见 ①「目标个数不影响布局」 |
| 同一 metric 是否可并存两条 | 否。`ensureSlotActive` 先 `getByMetricAny` 判存在性：存在则 `restoreGoal`（只翻 status，幂等），不存在才插入 → **写入天然幂等，不会产生重复行** |

**结论：目标不会"太多"。** 既无自由列表、也无无限新增路径，上限由指标白名单结构性封顶；再加 UI 显性禁用 + 写入幂等，三层都不会出现"目标过多"的异常。

⚠️ 唯一缺口是 **DB 层没有 `metric` 唯一约束**（防御性，非现存 bug）—— 当前不会触发，但一旦未来重构引入直插路径，`getByMetric(... LIMIT 1)` / `associateBy` / `setPrimary` 的 `CASE WHEN metric=` 都会**静默取到错值**。加固项见 ⑤·C3。

### 待确认问题
1. kcal 槽位定在"主目标之后"，还是按"新项追加末尾"（饮水之后）更好？
2. 迁移 hint 是否需要在"个人信息页"也留一条一次性的"已迁移"提示，还是只放目标栏？
3. 次目标删除是否需要保留最近一次值用于展示（当前规格：删除后不再展示，仅归档）？

## ③ 计划页时间轴（问题3 · 方案C）

### 功能规则
**分组与排序键**
- 时间轴按**日**分组，每日一个「日头」：`今天` / `明天` / `M月D日 周X`。
- 组排序键：`date` 升序。
- 组内排序键（元组）：`has_time DESC`（有具体时刻优先）→ 无时刻「训练」作为**全天项置顶** → 其余按 `HH:mm` 升序；早/午/晚锚点按其时段固定序 `早 < 午 < 晚`。
  - 等效排序元组：`(date asc, is_all_day DESC, slot_rank asc, hhmm asc)`，其中 `slot_rank`：全天训练=0，有具体时刻条目按其 HH:mm 折算，早/午/晚锚点=08:00/12:00/19:00 的占位序（不显示为时刻）。
- **今天**：维持按 `HH:mm` 排当日 吃/练/睡（显示具体时刻）。
- **明天**：在同一次生成里顺带产出**粗颗粒锚点**：`早 / 午 / 晚 / 训练`（4 条），**不显示 HH:mm**。
- **后天起**：仅一条无时刻的**训练日行**（全天项，置顶），文案 `训练日`。

**「明天」锚点颗粒度与文案形态**
- 每锚点一行，行高 ≥48dp：`accent 竖线(1dp，允许)` 或 6px 圆点 + 时段名（secondary13/text_2）+ 内容（body15/text_1）。
- 有内容：`早 · 燕麦牛奶 / 鸡蛋`（取该时段首 1–2 项，超出以 `…` 截断）。
- 无内容：内容位显示 `待安排`（text_3）；整行仍可点击进入详情/编辑。
- 训练锚点：`训练 · <动作摘要>` 或 `训练 · 待安排`。

**空态入口**
- 完全无计划：居中 caption `今天还没有计划`（text_2）+ 主文字按钮 `生成今日计划`（body15，按下态 accent）+ 次入口 `手动添加`（secondary13/text_2）。
- 仅某日为无：该日分组下显示单行 `待安排`（text_3），不重复空态。

**AI 重排中的在途提示**
- 触发（`生成今日计划`/`重排`）：按钮文字变 `重排中…`（text_2）并禁用；时间轴顶部插入一行 13sp text_2 `正在重排…` + 一条 1dp 不定长进度线（line 底 + accent 头，允许 1dp）。
- 重排期间**旧条目保持可见**（不整页 skeleton、不消失），完成后就地替换（不加动效）。

**失败 / 兜底 / 配额不足的提示分工**
| 场景 | 提示位置 | 文案 | 动作 |
|---|---|---|---|
| 服务/网络失败（可重试） | 时间轴顶部行内条 | `重排失败` | `点击重试`（text_2，按下 accent）；旧计划不变 |
| 兜底（无 AI / 解析失败） | 时间轴顶部行内条（弱） | `已用默认模板生成`（text_3） | 不报错，附 `手动调整` |
| 配额不足 | 时间轴顶部行内条 | `今日 AI 额度已用完` | 只给 `手动添加`，**不显示重试**（避免死循环） |

### 状态覆盖
| 状态 | 表现 |
|---|---|
| 空 | 见「空态入口」 |
| 加载 | 首次生成 = 顶部 1dp 进度线 + `正在生成…`；已有计划时重排见「在途提示」 |
| 成功 | 分组时间轴渲染；明天=锚点，后天起=训练日行 |
| 失败 | 见表格；保留旧数据 |
| 禁用 | 生成/重排按钮在"重排中"与"配额不足"时禁用 |

### 边界与异常
- 跨天切日：日头永远从"今天"起；昨晚未完成条目不出现在"今天"（沿用既有规则或置灰处理，待确认）。
- 明天锚点与今日条目冲突（同名/同项）：不做去重，允许重复。
- 无时刻锚点的排序在"同日内同时存在具体时刻条目"时，`早/午/晚` 按占位序插入到对应时段附近（见排序键）。
- 时区/午夜翻转：以设备本地日为准；翻转后"今天/明天"日头重算一次。

### 待确认问题
1. 无时刻锚点与具体时刻条目混排时，是否允许用户手动拖动重排？
2. "后天起"训练日行是否需要展示训练动作数（如 `训练日 · 3 个动作`）？
3. 配额不足是否提供"次日自动重试"开关，还是纯手动？

## ④ 全 App 巡检必改项

### 4.1 我的页违反「无卡片」
- **现状**：概览/数据/应用 3 组均用卡片容器 + 16dp 边距；其余页（设置/个人信息/状态详情/记录）为无卡片纯列表 + 20dp 边距。
- **交互裁决**：统一为**无卡片纯列表**——组标题 = caption12(text_3) section header；组内条目行高 ≥48dp；行间以 1dp `line`（左右各 20dp 内缩，与页边距对齐）；页左右边距统一 20dp；区块间距 28dp。数字类（概览）用 numeral/body 直接排版，**不进容器**。
- **影响面**：仅「我的」页；组语义与条目顺序不变，仅去除容器/阴影/16dp 边距。
- **是否加全局一致性条目**：**需要**（见「跨块共享约定」G1）。

### 4.2 二级页顶部文字 Tab 未选中态无层级
- **现状**：计划页/状态详情页顶部 Tab 用裸 `Text.Button` 未设色 → 与选中态同为 text_1，仅靠 2dp accent 下划线区分；底部导航明确"选中 text_1 / 未选中 text_2"。
- **交互裁决**：未选中态统一改 **text_2**（选中 text_1 + **2dp** accent 下划线；字重均为 500，不靠加粗区分）。下划线高 **2dp**（＝`dimens.tab_indicator`，与 `fragment_plan_review.xml` 实装一致）、圆角 1dp（§2.3「线高 ≤2dp 的元素可 1dp 圆角」的例外项，指的是**圆角**而非线高）。
- **影响面**：计划页、状态详情页顶部 Tab。**底部导航已合规，无需改**；其余页无顶文字 Tab。
- **全局一致性条目**：**需要**（见 G6，统一"选中/未选中/text/下划线"规范）。

### 状态/边界补充

## 跨块共享约定（Global Conventions）

| 编号 | 条目 | 约束 |
|---|---|---|
| G1 | **无卡片** | 全 App 无卡片容器/阴影/渐变；分区靠留白 + 1dp 细线。我的页、设置页、个人信息页、状态详情页、记录页一律符合 |
| G2 | **圆角** | 全局唯一 8dp；线高 ≤2dp 元素可 1dp，且**仅**用于进度线 / Tab 下划线 / accent 竖线 |
| G3 | **字重** | 只用 400 / 500，禁 600/700；层级由 字号/字重/灰度 决定，**不用颜色**表达层级 |
| G4 | **颜色** | 唯一强调色 `#B85028`；`positive#4A7C59`/`negative#A63D40` 仅用于文字与 6px 圆点，不铺面 |
| G5 | **间距** | 页左右边距 20dp；区块间距 28dp；触控热区 ≥48dp；列表分隔线左右各 20dp 内缩；**行内右对齐动作（「记一笔」/「已记录」等）文字右边界同样落在 20dp 线上**，不得贴到屏幕边 |
| G6 | **选中态规范** | 文字 Tab / 底部导航：选中 text_1 + **2dp** accent 下划线（顶 Tab，圆角 1dp）/ accent 图标（底导航）；未选中 **一律 text_2**；字重均 500 |
| G7 | **弹层规范** | 半屏 BottomSheet 统一：下滑 / 点遮罩 / 右上 `关闭`(text_2) 三关闭方式；无阴影，靠 1dp 顶线与 bg 对比区分 |
| G8 | **空态规范** | 纯文本 + 文字入口（caption/text_2/text_3），无插画、无容器、无 accent 铺底 |
| G9 | **删除=归档** | 所有"删除"落到 `goals.status=archived`，非物理删除；重加即复活 |
| G10 | **提示分级** | 可重试失败 → 行内 text_2 + 重试动作；兜底 → text_3 弱提示；配额/不可恢复 → 明确文案 + 替代动作，不给死循环重试 |
| G11 | **数量上限** | 可增删的目标槽位上限 **6 项**（主目标 1 + 次目标 5），由指标白名单结构性封顶；达上限时**入口置灰 + caption 说明**，不用"点完再弹 Toast"兜底 |
